# 📱 Mi Pokédex

Una Pokédex interactiva construida con **HTML, CSS y JavaScript puro (vanilla)**, que consume la [PokeAPI](https://pokeapi.co/) para mostrar información de Pokémon en tiempo real.

🔗 **Demo en vivo:** https://codebyjavier.github.io/Pokedex/

## ✨ Características

- 🔍 Búsqueda de Pokémon por nombre
- 🏷️ Filtrado por tipo (fuego, agua, planta, eléctrico, etc.)
- 📄 Carga progresiva de Pokémon ("Cargar más")
- 📋 Vista de detalle con información ampliada de cada Pokémon
- ♿ Enfoque en accesibilidad (roles ARIA, labels, `aria-pressed` en filtros)
- 📱 Diseño responsive

## 🛠️ Tecnologías

- HTML5 semántico
- CSS3
- JavaScript (Vanilla JS, sin frameworks)
- [PokeAPI](https://pokeapi.co/) como fuente de datos

## 🚀 Cómo correrlo localmente

```bash
git clone https://github.com/CodeByJavier/Pokedex.git
cd Pokedex
```

Luego simplemente abre `index.html` en tu navegador, o sirve la carpeta con una extensión tipo Live Server.
